Self-hosting and federation

Run your own instance. Or don't.

Venta is one client and many servers. Point it at ours and you have an account in a minute. Point it at your own and nothing about the app changes - same guilds, same calls, same encryption, on hardware you control.

Instances can also talk to each other. An admin starts a handshake with another host, the other side accepts - automatically or by review - and from then on the two are federated. Change your mind and you can defederate; that is a normal thing to do, not an escape hatch.

The server is open source

Venta's backend is public under AGPL-3.0. You can read exactly what you would be running before you run it, and anyone you host for keeps the same right. The mobile app, the Isle bridge and this website are public too - the desktop client is not, yet.
